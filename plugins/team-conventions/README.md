# team-conventions

Baseline Shark Software team conventions for Claude Code.

## Contents

| Component | Type | What it does |
|---|---|---|
| `code-style` | skill | Code style, commit message format (Conventional Commits) and pull request description structure |

> This is starter content. Replace the rules in `skills/code-style/SKILL.md` with the conventions the team has actually agreed on, and release a new version.

## Install

```bash
claude plugin install team-conventions@shark-plugins
```
